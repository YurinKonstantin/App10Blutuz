# BlueIDE Privacy Policy Template

Last updated: 2026-08-18

## Overview

BlueIDE is a Windows desktop application for Bluetooth terminal and BLE diagnostics.

## Data We Process

BlueIDE can access:

- Bluetooth device identifiers and names visible to Windows
- Bluetooth traffic that you send or receive inside the app
- Local app settings such as theme, presets, favorites, recent history, and trial state

## What We Do Not Collect

- We do not require user registration
- We do not send Bluetooth traffic to our servers
- We do not collect analytics, crash telemetry, or advertising identifiers
- We do not sell personal data

## Where Data Is Stored

Application settings, presets, favorites, and local logs are stored on the device using Windows app storage.

If you use export features, the exported files are saved only to the location you choose.

## In-App Purchases

BlueIDE PRO is unlocked through Microsoft Store in-app purchase APIs.
Purchase processing is handled by Microsoft. BlueIDE receives only license state needed to unlock PRO features.

## Permissions

BlueIDE requests Bluetooth access to discover devices and communicate with supported hardware.
