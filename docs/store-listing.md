# BlueIDE Store Listing

## Positioning

BlueIDE is a Windows desktop tool for Bluetooth Classic serial work and BLE diagnostics.
Primary audience: ESP32, Arduino, HM-10, HC-05, Nordic, embedded, IoT, hardware QA, reverse engineering.

## Suggested Title

BlueIDE - Bluetooth Terminal, BLE Scanner & GATT Analyzer

## Short Description

Free Bluetooth terminal for Windows. Scan Classic and BLE devices, pair, send HEX or text over RFCOMM/SPP, and debug faster with presets. PRO adds GATT analyzer, echo server, and macros with a 14-day trial.

## Long Description

BlueIDE is a Bluetooth toolbox for Windows 10/11 focused on real device work, not toy demos.

Use it as a Bluetooth serial terminal for Classic RFCOMM/SPP modules, or switch to BLE analysis for GATT exploration and low-level diagnostics.

### Free features

- Scan nearby Bluetooth Classic and BLE devices
- Pair and reconnect to supported devices
- Send and receive UTF-8 text or HEX payloads
- Save command presets and reuse command history
- Filter devices by name or MAC address
- Run on Windows 10/11 across x86, x64, and ARM64

### BlueIDE PRO

- BLE GATT analyzer with services, characteristics, descriptors
- Read, write, notify, and inspect raw values
- Built-in Bluetooth echo server for loopback testing
- Command macros for repetitive workflows
- Traffic export for diagnostics and support cases

### Trial and purchase model

BlueIDE is free to install and use as a Bluetooth terminal.
PRO tools include a 14-day trial that starts when you first open a PRO feature.
After the trial, a one-time in-app purchase unlocks PRO permanently for the signed-in Microsoft account.

### Good fit for

- ESP32 and Arduino serial consoles
- HC-05 / HC-06 / HM-10 bring-up
- BLE sensor inspection
- Nordic UART and custom GATT workflows
- Manufacturing tests and field diagnostics

### Privacy

BlueIDE does not require account creation.
Bluetooth data stays on the device unless you explicitly export logs.
